Writing style — extra instructions for the AI writer (optional · up to 4,000 characters)

Every article is already written in the house voice: a professional, friendly writer who hooks the reader in the first lines, keeps it practical and easy to scan, and avoids cringe phrases (no scare tactics, no emojis). Add anything you want on top — tone, words to use or avoid, how to talk about Pakistan, things patients ask you about. Facts, honesty and medical-safety rules always stay on.


        

        
      

      

        
AI

        
Pick any AI service you have a key for. Each service keeps its own saved key, so you can switch between them without pasting keys again. Keys are stored on the server only — they are never shown again or sent to visitors' browsers. Free to start: Google Gemini, Groq, Cerebras, Mistral, OpenRouter (models ending in :free), GitHub Models and Z.ai GLM Flash.

        

          
          
          
        

        

        

          
        

        

        

      

      

        
Images

        
        
Openly licensed photos (CC0, Public Domain, CC BY, CC BY-SA) are saved to your own storage and always shown with the photographer's credit and licence. Free AI image generation isn't available, so the agents don't generate images.

      

      

        
Fonts

        
The default fonts for every guide. Urdu guides use Nastaliq: by default a display Nastaliq (Gulzar) for titles, a bold Nastaliq for sub-headings and a regular Nastaliq for the text. Press Save settings — live guides update within about a minute.
